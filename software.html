Open-source Scientific Software

Scientific software and computational tools developed to support reproducible research in atmospheric science and climate dynamics. These projects aim to make established methods more accessible to the broader scientific community.

ACTIVE PROJECT · PYTHON

PyWKSpectra

An open-source Python package for Wheeler–Kiladis space–time spectral analysis of tropical atmospheric variability. PyWKSpectra provides tools for studying convectively coupled equatorial waves, including spectral diagnostics, visualization capabilities, and reproducible examples.

LEGACY SOFTWARE · DISCONTINUED

wk_spectra

An earlier Python implementation of Wheeler–Kiladis spectral analysis. This repository is no longer maintained and has been superseded by PyWKSpectra. It is retained as part of the development history of the software.
